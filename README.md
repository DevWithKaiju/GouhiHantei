# GouhiHantei

## これはなに

PDF で合格者の受験番号が特定の Web ページに掲示される形式の入試について、合否を判定できるアプリです。
合格発表ページの URL と受験番号を入力すると、掲示 PDF の中に自分の受験番号があるかを調べます。

ブラウザ上で動く GUI アプリ（Streamlit 製）です。

なお、合否が正しく表示されなかった場合に生じる不利益については、責任を負いかねますのでご了承ください。
最終的な合否は必ず公式の発表でご確認ください。

## 使い方

### 準備（初回のみ）

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

### 起動

```sh
./run.sh
```

### ファイル構成

| ファイル | 役割 |
| --- | --- |
| `app.py` | アプリ本体 |
| `style.css` | 掲示物としての体裁（app.py が読み込む） |
| `.streamlit/config.toml` | 本文フォントとテーマ色 |
| `run.sh` | 起動用。初回は仮想環境の作成と依存の導入も行う |
| `requirements.txt` | 依存パッケージ |

`app.py` は単体では動きません。`style.css` と `.streamlit/` も一緒に置いてください。

仕組みや設計上の判断については [ARCHITECTURE.md](ARCHITECTURE.md) を参照してください。

ブラウザが自動で開きます。開かない場合は http://localhost:8501 にアクセスしてください。
終了するときは、起動したターミナルで `Ctrl + C` を押します。

### 画面の流れ

1. **合格発表ページの URL** を入力して「発表ページを読み込む」を押す
   - 例：`https://www.f.u-tokyo.ac.jp/exam/index.html?key=1378943625`
2. ページ内で見つかった PDF の一覧から、**合格者一覧を選ぶ**
   - 掲示が多いときは、キーワード（例：`修士課程合格者 2026.10`）で絞り込めます
3. **受験番号**を入力して「照 会 す る」を押す

合格者一覧の PDF の所在がすでに分かっている場合は、画面上部で
「PDF の所在を直接指定する」に切り替えてください。

### 照会結果について

| 表示 | 意味 |
| --- | --- |
| 合格 | 受験番号が独立した番号として PDF 内に見つかった |
| 要確認 | 他の受験番号の一部に含まれていただけの可能性がある（抜粋を要確認） |
| 該当なし | PDF のどのページにも含まれていない |
| 照会不能 | PDF から文字を取り出せなかった（画像として取り込まれた PDF など） |

受験番号は全角で入力しても半角に変換して照合します。

「要確認」は、番号が他の文字列の一部としてのみ見つかった場合に出ます。
他人の番号の一部を拾っただけのこともあれば、PDF から文字を取り出した際に
番号どうしの区切りが失われて本当は合格でもこの表示になることもあるため、
画面に出る該当箇所の抜粋で確認してください。

### うまくいかないとき

| 表示 | 原因 |
| --- | --- |
| PDF ではなく Web ページでした | PDF 以外のリンクを選んだか、掲示が移動・削除されている |
| 取得が途中で終わりました | 通信が切れた。もう一度試す |
| 該当する掲示がありません | 絞り込みのキーワードが厳しすぎる |

SSL 証明書を検証できないサイトでは、検証を省略して取得したうえでその旨を画面に表示します。
